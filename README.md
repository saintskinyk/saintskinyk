## Hi, I'm saintskinyk! 👋

I spend most of my time writing Rust and C, usually somewhere between the kernel and the user. I'm drawn to the kind of work where you can feel every allocation — terminal utilities, WebAssembly runtimes, anything where the machine isn't hidden behind five layers of abstraction. Lately I've been thinking a lot about what "fast enough" really means, and whether the answer changes depending on who's waiting.

- 🔭 A small CLI profiler for tracing syscall latency in long-running processes.
